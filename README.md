## About

I'm a full-stack software engineer whose deepest expertise is the frontend —
React and Next.js architecture, state and data-fetching design, and
interfaces built to stay fast under real production traffic. That focus has
never stopped at the browser: I design and ship the Django, Nest.js, and Go
services behind those interfaces, along with the Docker and Kubernetes
pipelines that deploy them.

In production I've built mobile-first PWAs with autoscaled Kubernetes
delivery, a real-time analytics pipeline sustaining over 1,000 requests per
second on Socket.io and Redis, and admin platforms that let non-engineers run
campaigns end to end — almost always with UI built in-house rather than
assembled from a kit.

I'm also a Computer Engineering student at Sharif University of Technology
(GPA 18.01/20, ranked 34th out of 140,000+ in Iran's national university
entrance exam), and I've spent the last several years teaching there —
teaching assistant for more than twenty courses, five of them as Head TA.
Explaining a system clearly and designing one well turned out to be close to
the same skill.
